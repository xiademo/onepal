启动教程

  1. 进入项目目录cd D:\git\ai\workspaces\onepal
  2. 启动本地 API 与健康检查powershell -ExecutionPolicy Bypass -File scripts\start_onepal.ps1
  3. 浏览器将打开本机工作台http://127.0.0.1:18790/dashboard/
  4. 在“远程模型配置”中填写 Base URL、模型名和 API Key，再点击“检测远程连接”。
  5. 到“模型 / 成本”面板勾选远程发送确认后，才可以生成提案。提案不会自动写入记忆、任务或外部系统。
  6. 停止服务powershell -ExecutionPolicy Bypass -File scripts\stop_onepal.ps1
