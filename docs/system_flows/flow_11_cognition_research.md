# SF-11｜Frontier Research & Cognitive Expansion Flow｜前沿研究与认知拓展链路

> Agent 7 正式名称统一为 Deep Research & Cognition。Tutor 是其教学型子能力，不作为 Agent 名称。


## 1. 定位

基于 Research Packet、知识地图、用户知识图谱和反馈，生成前沿科技雷达、认知卡片、深度研究报告、教学内容，并维护认知边界图谱。

## 2. 主责

- 主责：Agent 7 Deep Research & Cognition
- 协作：Coordinator、Task Tree Engine、流程 02 审批、流程 14 健康治理、流程 15 备份回滚、流程 16 Runtime（按需）

## 3. 典型触发

- 每日认知主题
- 前沿科技雷达
- Research Packet 移交
- 知识图谱空白
- Agent 8 知识解释请求

## 4. 核心对象

- Cognition Need
- Topic Queue
- Research Brief
- Evidence Pack
- Synthesis
- Teaching Output
- Knowledge Graph Update Candidate
- Growth Suggestion

## 5. 标准执行骨架

```text
Intake / Request
↓
Classification / Scope
↓
Risk & Policy Check
↓
Owner Agent Handling
↓
Output / State / Handoff
↓
Audit / Health / Review
```

## 6. Dashboard 对应区域

该流程应在对应 Center 中展示：状态、待处理项、最近运行、风险等级、下一步动作、是否需要审批。

## 7. 关键硬规则

1. Agent 7 不做普通搜索，需资料时走流程 10。
2. Agent 7 不直接制定学习计划，长期学习交给 Agent 8。
3. 知识图谱只把自动输出默认标记 exposed。
4. 前沿内容必须标注不确定性，低质量主题可以跳过。
