# Process Chains — 16 条流程链路

## 1. 模糊需求结构化与路由
User Input → Coordinator → Structuring Prompt → Clarify if needed → Route to Agent

## 2. Proposal / Approval 审批
Proposal Created → Approval Queue → User Approve/Reject → Execute or Discard

## 3. 记忆捕获、审核、合并、归档
Capture → proposals.json → Approve → store.json → Decay → Archive

## 4. OpenCode 工程实现
Plan Mode → Architecture Review → Build Mode → Changes → Verification

## 5. 外部能力招聘
Search GitHub → Add Candidate → Request Download (Approval) → Clone → Install Markdown (Approval)

## 6. 内部 skill 生成与比武
Draft Skill → Create Proposal → Approve → Write to skills/installed/ → Register in index.json

## 7. 功能组装 Feature Assembly
Feature Request → Check Registry → Route to opencode_builder → Implement → Verify

## 8. 文档输入与 MarkItDown 转换
Input File → data/input/ → Detect → Convert → data/markdown/ → Memory Proposal (optional)

## 9. 定时任务与系统健康检查
Schedule Trigger → Coordinator → Run Feature → Log Result → Update Health

## 10. 平台与软件更新检查
Periodic Check → OpenCode/ Version → Report → User Action

## 11. TrendRadar 定时信息雷达
Timer → research_scout → Scan Feeds → Summarize → Memory Log

## 12. 主动搜索情报
User Query → research_scout → GitHub Search → Summarize → Present

## 13. 前沿深度解读
Topic → deep_research_tutor → Multi-Source Analysis → Structured Report → Memory

## 14. 每日认知拓展与知识图谱更新
Daily Trigger → goal_growth_planner → Review → Learn → Update Knowledge

## 15. 目标型成长规划
User Goal → goal_growth_planner → Decompose → Track → Review → Adjust

## 16. 职业资产、JD 机会池与求职表
JD/Resume Input → career_asset_jd_agent → Match Analysis → Opportunity Pool → Track
